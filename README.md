# Workspace Focus for Paseo

独立的侧栏插件：将有明确父 agent 关系的派生工作区收进紧凑折叠行，显示 agent 总数和运行数。展开后仍使用原生工作区入口。

## 安装

在已开启插件功能的 Paseo daemon 主机上执行：

```sh
paseo plugin add git:leansz-coder/paseo-workspace-focus --ref v0.1.2
paseo plugin ls
```

插件 ID 为 `workspace-focus`，适用 Paseo `>=0.11.1 <0.12.0`。只使用宿主模块，无需额外生产依赖。插件是不受沙箱隔离的可信代码，请只安装信任的版本。

## 使用

侧栏“工作区聚焦”打开来源详情与设置。默认对所有项目开启保守折叠，可按项目排除，或把工作区设为常驻。

- 只有所有未归档 agent 都有其他工作区的父 agent，才判为派生工作区。父级元数据包含已归档 agent，但计数不含它们。
- 来源未知、混合、空、置顶、当前选中和用户设为常驻的工作区保持可见。来源表示父子关系，并非实际创建者审计。
- 首次进入某主机后，侧栏装饰由该主机插件实例持续维护；切换到其他主机标签页不撤销已建立的折叠。主题更新不重建分组，手动展开状态保留到插件卸载。
- 运行数取自 agent 状态；绿色未读标记不等于正在运行。单个空闲 agent 不额外占一行，完整统计在详情和提示中。
- 列表每页 200 项，继续读取全部分页。数据未完整或任一订阅失败时停止隐藏；恢复后再折叠，也可点“重新读取”。

## 边界

侧栏折叠依赖桌面/Web 页面结构；原生手机仅支持详情页，尚无侧栏折叠。已在 macOS 桌面 Paseo 0.11.1 检查，原生手机未做真机验证。

偏好在桌面/Web 按主机保存在当前客户端，不跨设备同步；原生手机的偏好仅在当前加载期间有效。仓库不包含任何人的主机 ID、工作区常驻名单或聊天记录。

插件只读订阅 agent 和工作区元数据，不读取聊天正文，也不停止、发送、归档或删除会话；不向第三方发送数据。卸载或停用会移除装饰、恢复原有显示。宿主 DOM 升级后需复核兼容性。

## 更新与回退

```sh
paseo plugin update workspace-focus
paseo plugin update workspace-focus --ref v0.1.2
paseo plugin disable workspace-focus
```

更新只热加载插件，不需要重启 daemon。首次安装的 `--ref` 不会永久固定未来更新。
